# Contributing to DeepfakeDetector

Thanks for your interest in improving this project!

## Workflow
1. Fork the repository and create a branch: `git checkout -b feature/short-description`
2. Set up the environment as described in the README.
3. Make your change with tests where it makes sense.
4. Run `pytest` and `flake8` before committing.
5. Open a pull request using the PR template.

## Commit messages
Use short, imperative messages, e.g. `Add rate limiting to /upload`. Conventional prefixes
(`feat:`, `fix:`, `docs:`, `test:`, `chore:`) are welcome.

## Code style
- Python 3.10+, PEP 8, max line length 120.
- Keep functions small and documented with docstrings.

## Reporting security issues
Please do **not** open a public issue. See [SECURITY.md](SECURITY.md).
