Three-tier fallback (highest quality first):

  1. Trained CNN-LSTM (your own model, matches project report) — see below
  2. Pretrained Vision Transformer (Hugging Face, no training needed) — pip install transformers + internet connection once
  3. Classical-CV heuristic baseline (always available, fully offline)

To train your own CNN-LSTM (recommended for real accuracy):

1. Download one or more labeled datasets (e.g. Kaggle DFDC sample set)
2. Sort each one into data/real/ and data/fake/:
   python prepare_dataset.py --source-dir ./downloads/dfdc_sample --metadata metadata.json
3. Repeat step 2 for additional datasets (--prefix to avoid filename clashes)
   -- everything merges into the same data/real and data/fake folders
4. python train.py --data-root ./data --epochs 15 --batch-size 4
5. Restart the Flask app — it auto-detects saved_models/deepfake_cnn_lstm.pt

train.py automatically handles class imbalance (common in these datasets) and reports precision/recall/F1, not just accuracy.
