Project Abstract

The rapid increase in deepfake videos and images has raised the urgent need for effective detection methods to counter misinformation and malicious content. Deepfakes, created using advanced AI, produce highly realistic synthetic media, making it difficult to distinguish between authentic and manipulated content, posing threats to media authenticity and public trust.

This project develops a deepfake detection system that combines Convolutional Neural Networks (CNNs) and Recurrent Neural Networks (RNNs), specifically Long Short-Term Memory (LSTM) networks, to enhance detection accuracy. CNNs extract spatial features from video frames, while LSTMs capture temporal dependencies across the frame sequence — together forming a hybrid architecture capable of catching both single-frame artifacts and unnatural motion over time.

Transfer learning further improves model performance by pre-training the CNN backbone on large datasets before fine-tuning on deepfake-specific data. The system analyzes spatial and temporal patterns to detect anomalies across diverse conditions such as lighting, resolution, and facial pose. Regularization (dropout) and data augmentation address overfitting and adversarial robustness, and standard evaluation metrics (accuracy, precision, recall, F1, ROC-AUC) assess system effectiveness.

This implementation ships as a complete, working full-stack application: a Flask backend orchestrates video upload, OpenCV-based frame/face extraction, and model inference; a PyTorch CNN-LSTM model (trainable via train.py) provides the deep-learning classifier; and when no trained checkpoint is present yet, an explainable classical-CV heuristic baseline (frequency analysis, sharpness, texture entropy) keeps the system fully functional out of the box.
